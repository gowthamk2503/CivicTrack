## 🐛 SOMETHING NOT WORKING?

1. **Python not found?**
   → Install from https://www.python.org/
   → Check "Add Python to PATH"

2. **Setup fails?**
   → Read INSTALLATION_WINDOWS.md
   → Try manual setup in README.md

3. **App won't start?**
   → Delete database.db
   → Try running again

4. **Port 5000 in use?**
   → Edit app.py, change 5000 to 5001
